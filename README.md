# 🌍 Simple World Sync

> Synchronize your Minecraft worlds between devices — automatically and without hassle.

[🇷🇺 Русский](#-русский) • [🇬🇧 English](#-english)

---

## 🇷🇺 Русский

### 📌 Описание

**Simple World Sync** — клиентский Fabric-мод для Minecraft, который синхронизирует одиночные миры между устройствами.

💡 **Ключевая особенность:**  
мод работает **напрямую через API Яндекс Диска**, без папок синхронизации и сторонних программ.

---

### 🚀 Как это работает

✔ без Syncthing  
✔ без облачных клиентов  
✔ без ручных копирований  

---

### ✨ Возможности

- ☁️ прямая синхронизация через Яндекс Диск API  
- 🔐 безопасная OAuth-авторизация (без логина/пароля в игре)  
- 🔄 инкрементальная синхронизация (только изменённые файлы)  
- 📤 автоматическая выгрузка при выходе из мира  
- 📥 автоматическая загрузка перед запуском  
- 📊 отображение прогресса (скорость, %, время)  
- 🔒 защита от конфликтов (lock-система)  

---

### 🔐 Авторизация

1. Нажмите **«Войти в Яндекс»**
2. Откроется браузер
3. Подтвердите доступ
4. Всё готово

> 🔒 Ваши логин и пароль НЕ передаются в Minecraft

---

### 📁 Где хранятся миры
/SimpleWorldSync

в вашем Яндекс Диске.

---

### ⚠️ Важно

- ❗ Не запускайте один и тот же мир на двух устройствах одновременно  
- ⏳ Дождитесь завершения синхронизации  
- 🐢 Первый запуск может занять время  

---

### 🚧 Ограничения

- Возможны ошибки `423 Locked` со стороны Яндекс Диска  
- Большие миры (5–20 ГБ) синхронизируются постепенно  
- Скорость зависит от API Яндекса

## 🇬🇧 English

### 📌 Description

**Simple World Sync** is a client-side Fabric mod for Minecraft that syncs singleplayer worlds between devices.

💡 **Key feature:**  
works **directly via Yandex Disk API**, without sync folders or external tools.

---

### 🚀 How it works
PC
↓
Yandex Disk (API)
↓
another device

✔ no Syncthing  
✔ no cloud clients  
✔ no manual copying  

---

### ✨ Features

- ☁️ direct Yandex Disk API integration  
- 🔐 secure OAuth login (no password in-game)  
- 🔄 incremental sync (only changed files)  
- 📤 auto upload on world exit  
- 📥 auto download before play  
- 📊 sync progress (speed, %, time)  
- 🔒 conflict protection  

---

### 🔐 Authentication

1. Click **Login with Yandex**
2. Browser opens
3. Confirm access
4. Done

---

### ⚠️ Notes

- Do not open the same world on multiple devices  
- Wait until sync is complete  
- First sync may take time
