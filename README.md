## 🇷🇺 Русский

### 📌 Описание

**Simple World Sync** — клиентский Fabric-мод для Minecraft, который синхронизирует одиночные миры между устройствами.

💡 **Главное:** мод работает **напрямую через API Яндекс Диска**, без папок синхронизации и сторонних программ.
